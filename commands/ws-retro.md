Trigger the `synthesis-retro` skill in `full` mode. Honor explicit alternate modes: `post-mortem` (adds timeline structurer + cause-vs-blame check), `project` (adds "what we would have done differently" section).

The recipe's 7-step pipeline (9 with post-mortem variant) pauses at:
- Step 3 — you write the theme interpretations
- Step 4 — you pick the action items (3–7 max, named, dated)
- Step 7 — the pre-send check is social work, not model work; send the draft to a real person from the room

One rule above all: **the minority view is the data, not the noise.** The agent refuses to soften minority-view language without explicit user override.

Uses opus per project policy for dissent-preserving work.
