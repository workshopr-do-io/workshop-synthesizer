## Why these twelve

Across the six recipes in the book, there are 26 named prompts. Twelve of them — the workhorses — show up across multiple recipes. The other 14 are recipe-specific.

Tradesperson analogy from the book: a cabinet restorer with 12 tools who's tried bigger rolls. The 12-tool roll keeps coming back. *If I need a thirteenth tool, I usually need to slow down and think about whether I'm working the right problem.*

## When you've internalized the twelve

You can build new recipes for workshop types this plugin doesn't cover. See [`extending-the-recipes.md`](extending-the-recipes.md) for the five-step pattern.

## How the twelve compound

Each new recipe contributes prompts that may become part of the roll. Each prompt in the roll makes the next recipe faster to build. The library compounds.

The book's six recipes were built in roughly this order:
1. Discovery (took 6 months of real engagements before the prompts stabilized)
2. Strategic offsite
3. Design sprint (took 6 weeks because R1 had done most of the grammar work)
4. Ideation/roadmap
5. Retro/post-mortem (2 weeks)
6. Training debrief (the pattern was muscle memory by then)

## The shrinkage discipline

Every quarter, look at the library and prune. For each workhorse: have I used this in the last quarter? If yes, keep. If no, ask why.

The library either stays the same size or gets smaller. Almost never bigger. This goes against the instinct of every facilitator who builds a library — to *add* prompts. Resist.

See [`versioning-discipline.md`](versioning-discipline.md) for the full versioning + shrinkage pattern.
