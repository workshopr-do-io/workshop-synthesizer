# Audience-Tiered Narrator (Reference)

See [`/prompts/workhorses/audience-tiered-narrator.md`](../../../prompts/workhorses/audience-tiered-narrator.md) for the full discipline.

## Quick summary

Drafting the same content at multiple altitudes for different readers — personal, operational, executive, board.

This is workhorse #11. Not a single prompt; a discipline implemented by several recipe-specific prompts (CEO memo draft assist, retro write-up drafter, cohort-pattern surfacer, etc.).

## When to apply it

Three workshop types where audience-tiering is the whole game:

- **Strategic offsite** — three artifacts at three altitudes (CEO memo, board deck, confidential appendix)
- **Training debrief** — three artifacts at three altitudes (participant write-up, cohort analysis, budget-holder one-pager)
- **Large discovery** — usually two altitudes (deck + brief)

In other recipes, audience-tiering matters less — one artifact, one altitude.

## The altitude-check discipline

Before shipping a multi-artifact synthesis, read all artifacts back-to-back in altitude order (personal → operational → executive → board). Ask:

1. Is anything in the board deck that should only be in the personal memo? Move it.
2. Is anything in the personal memo that should only be in the appendix? Move it.
3. Is anything missing from the appendix that you wrote down on Day One? Put it back.

The artifacts only work if the altitudes are clean.
