## How to use it

Pin yourself on the matrix **before you start** synthesizing. Write the quadrant into the Reference section of your synthesis-ready file. *This engagement is high stakes, low politics — top left.*

## Three common mistakes

1. **Pinning to the wrong quadrant because the workshop "felt easy."** Low-key vibes don't mean low stakes. A retro that ended in laughs can still be a high-politics synthesis if a key person is signaling departure.
2. **Re-pinning mid-synthesis because the recipe got hard.** If you're tired and want to outsource [INTERPRET], the matrix is supposed to stop you. Don't move to a lower-stakes quadrant to justify the shortcut.
3. **Treating high/high as the default.** If you put yourself in the hardest quadrant every engagement, you'll burn out. Pin honestly.
