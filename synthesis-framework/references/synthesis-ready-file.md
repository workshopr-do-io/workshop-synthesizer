# The Synthesis-Ready File

Before the workshop ends, build one thing that saves your weekend more than anything else in the stack. A single document that holds links and pointers to every piece of capture from the workshop, organized in advance.

This is the synthesis-ready file. Build it once, save it as a template, fill it out before you leave the room on Friday.

## The template

```
Synthesis pack — [Client] [Workshop type] [Date]

Capture
- Miro board: [link]
- Sticky export (CSV): [link to file]
- Whiteboard photos: [folder link]
- Voting results: [link]
- Decision log: [link]

Transcript
- Day 1 full transcript: [link]
- Day 2 full transcript: [link]
- Closing discussion (audio): [link]
- Pre-read responses (if collected): [link]

Reference
- Workshop goal (one line): [paste]
- Pre-workshop hypotheses: [paste]
- Stakeholder list with roles: [paste]
- Deliverable spec (audience, format, date): [paste]
- Privacy/consent framework (GDPR / HIPAA / etc., if applicable): [paste]

Workspace
- Working markdown for synthesis: [link to file]
- Cluster drafts: [folder]
- Prompt log: [folder]
```

## Why this saves your weekend

The worst part of Sunday-afternoon synthesis is hunting:

- *Where is the Miro board?*
- *What was the goal again?*
- *Which voting round was the real one?*
- *Did anyone capture that whiteboard photo?*

The synthesis-ready file kills the hunt before it starts. Forty minutes on Friday afternoon. Hours saved on Sunday.

## The other thing the file does

The Reference section forces you to declare your hypotheses out loud before you start synthesizing. *Going in, I thought the team would say X.*

If you don't write that down, you'll never know if you ended up reverse-engineering your synthesis toward your starting belief. With it written down, the model can stress-test you against it, and you can catch yourself.

## What's different per workshop type

Each recipe adapts this template:

- **Discovery** — add interview guide, interviewee list with role + tenure + pre-known context, the one-sentence hypothesis you'll either confirm or break
- **Strategic offsite** — add the Day-One Read brief (you write it before sleeping on the first night), the stakeholder map (who reports to whom), the CEO's pre-existing position
- **Design sprint** — add the Decide-stage artifacts (winning sketch + alternatives + vote breakdown), the sprint hypothesis
- **Ideation** — add the HMW prompts, the evaluation criteria, the dot-vote tally
- **Retro** — add the discussion transcript, the feelings-temperature read, the pre-existing context (what the team committed to at start of quarter)
- **Training** — add each participant's 30-60-90 plan, pulse survey responses, co-facilitator observation notes, closing-circle recording, baseline-to-close pair foundation

See each recipe's `workflow.md` for the recipe-specific version.

## The discipline

**If you take one practical thing from Part 1 of the book, take this: build a synthesis-ready file template by the end of this week. Reuse it. Stop hunting.**
